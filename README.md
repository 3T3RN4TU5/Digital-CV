# Jeevan: digital CV

A one-page CV for a full-stack developer covering MERN, REST APIs, data analytics and ML, with an animated Three.js particle background.

**Live:** https://digital-cv-mu-dun.vercel.app

![Dark hero with the name JEEVAN over a Three.js particle field](docs/screenshot.jpg)

## Built with

A single `index.html` with HTML, CSS, JavaScript and Three.js (r128, from a CDN).

## Run it locally

Open `index.html` in a browser.
